# Release Notes

Every time your squad ships something, add a short entry at the top. Newest
release goes first. Keep each entry to what a user would notice.

## Format

```
## v1.0 - 2026-11-07

### Added
- Added an expense-deletion feature to remove incorrect budget entries (#4).

### Fixed
- Fixed a bug where empty inputs caused the terminal script to crash.
```
